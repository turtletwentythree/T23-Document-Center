# T23 Document Center

Web app สำหรับกรอกเอกสาร BTS / TURTLE จำนวน 9 แบบ

## Included documents
1. LG16 — Company Document Request
2. LG17 — Contract Review Request
3. POA — FSQ
4. Proposal Memorandum — FSQ
5. Terms & Conditions of Contract
6. Approval Memorandum
7. Approval Request Memo
8. PDPA Contract Request
9. Accrued Expense Form

## Functions
- Dashboard
- Search / Filter
- Editable A4 document forms
- Browser draft auto-save
- Print / Save PDF
- Export filled HTML
- Clear form
- Activity log
- CRT mode

Open `index.html` directly or deploy the folder to Vercel.
